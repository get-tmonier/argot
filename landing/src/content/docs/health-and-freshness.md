This legacy reference route remains for existing links. [Init and Fit](/docs/init-and-fit/) owns the
setup, health, and refresh workflow: use `argot inspect` to read the current fit verdict and
`argot fit` when you intentionally rebuild local artifacts after a configuration or source-layout
change.

For configuration keys such as `[fit]`, see [Configure](/docs/configure/). For how a selected
changeset is scored, see [Check a changeset](/docs/check/).
