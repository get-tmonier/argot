This page remains available for existing links. The step-by-step command workflow now has one
canonical owner per task:

- [Audit accepted history](/docs/audit/) — inspect accepted history without changing your tree.
- [Init and Fit](/docs/init-and-fit/) — create portable configuration and maintain the local voice.
- [Check a changeset](/docs/check/) — select changes, read findings, and interpret exit codes.

For the complete live command surface and advanced flags, run `argot --help` or
`argot <command> --help`. Configuration syntax, rules, and durable suppressions are documented in
[Configure](/docs/configure/).
