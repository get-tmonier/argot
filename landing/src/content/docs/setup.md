This legacy setup route is kept for bookmarks and incoming links. For first-time setup, use
[Init and Fit](/docs/init-and-fit/): `argot init` creates portable `argot.toml`, fits the local
voice, and reports its health. `argot init --suggest` only reports possible exclusions; review the
suggestions, edit the configuration if appropriate, then run `argot init` again.

Use [Configure](/docs/configure/) for the full configuration reference, [Check a changeset](/docs/check/)
for the review loop, and [CI and pre-commit](/docs/ci/) for integrations you choose to configure.
