# Changelog

argot ships on an automated release cadence — every merge to `main` bumps the
patch version, tags it, and `cargo-dist` publishes a **[GitHub Release](https://github.com/get-tmonier/argot/releases)**
with binaries, installers, and generated notes.

**The [Releases page](https://github.com/get-tmonier/argot/releases) is the
canonical changelog.** It's per-version, always current, and never drifts from
what actually shipped — which a hand-maintained file inevitably does.

For the deeper story behind the scorer's behaviour across versions, see the
[research log](docs/research/README.md).
